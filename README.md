# Raspberry Pi Cookbook 5th Edition Code

This is the official code repository for the 5th edition of the Raspberry Pi Cookbook.

You will find Python examples in the *python* folder and MicroPython (for the Raspberry Pi Pico) in the *pico* folder.

There are also a number of *other* files including a document of *long_commands* to save you typing in long shell commands if you are using a paper copy of the book.

You can find more information on the book, including where to buy it at the books website: [https://simonmonk.org/pi-cookbook-ed5](https://simonmonk.org/pi-cookbook-ed5)
